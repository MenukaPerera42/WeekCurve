# WeekCurve Brand Assets

These files are concept-stage brand assets for the Xaventra SE assessment.

## Brand
- Name: WeekCurve
- Tagline: Plan the week. Ship the goal.
- Primary navy: `#111C30`
- Secondary navy: `#243A59`
- Platinum silver: `#AAB5C3`
- Light platinum: `#DDE4ED`
- White: `#FFFFFF`
- Light surface: `#F7F9FC`
- Dark surface: `#0B1220`

## Files
- `logos/weekcurve-logo-light.svg` — Full logo for light backgrounds.
- `logos/weekcurve-logo-dark.svg` — Full logo for dark backgrounds.
- `icons/weekcurve-favicon-light.svg` — White background, navy W-arrow.
- `icons/weekcurve-favicon-dark.svg` — Navy background, platinum W-arrow.
- PNG files are previews/exported variants.

The W-arrow symbol doubles as the first letter in the wordmark (`eekCurve` to its right); the full brand name is **WeekCurve**.
